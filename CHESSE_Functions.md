# Chesse

- Iniciar projeto e estrutura automaticamente
- Configurar quais camadas deseja utilizar entre as seguintes: API, Application, Configuration, Core, Domain, Infrastructure, Shared, Tests.
- Configurar quais praticas deseja utilizar: Interfaces, Services, Repostiories, Controllers, Usecases e até mesmo retirar o uso de novas camadas personalizadas pelo próprio desenvolvedor.
- Adicionar arquivos para a criação de novas camadas
- Configurar arquivos que serão criados seguindo um modelos e seus comandos. Com alguns por padrão já definidos.
- Utilizar múltiplas linguagens
- Arquivo de configuração no formato Json, podendo ser criado apenas o arquivo primeiramente para então iniciar um projeto baseado nele, ou então utilizar o modelo completo com todas as camadas e configurações padrão.
--- 
- *A personalização pode ser feita sem alterar o código fonte porém é um trabalho um tanto quanto robusto, com grande parte já configurado porém a configuração completa será complexa
